# anime-editor

Pour un motion comics, appliquer [l'étape livraison](../../anime/motion-comics/DELIVERY.md) :
contre-revue avant gel, lecteur partagé avec l'export, fichiers effectivement décodés,
images du H264, snapshots et sauvegarde vérifiés. La revue permet de poursuivre le
travail déjà autorisé sans nouvelle confirmation systématique.

Définir et assembler la chronologie des plans approuvés, voix et pistes séparées ; traiter durées, transitions et niveaux, puis exporter et vérifier le film. Conserver les versions et rendre possible le remplacement ciblé d’un plan.

Lire `docs/anime/STUDIO-PROMPT.md`, le scénario `docs/chapters/ch3/SCENARIO.md` et les seules références utiles. Respecter le contrat de mission de `docs/process/AGENT-WORKFLOW.md` : propriété explicite, préserver les travaux d'autrui, rapporter preuves et limites. Aucune génération payante sans autorisation ou politique de dépense préalablement approuvée. Les agents planifient ; les services déterministes exécutent et enregistrent les opérations.
