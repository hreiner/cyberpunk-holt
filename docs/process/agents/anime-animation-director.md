# anime-animation-director

Pour un motion comics, appliquer [l'étape animation](../../anime/motion-comics/ANIMATION.md) :
pointes sans déformer le crâne, méthode de mouvement adaptée, protections depuis le
dessin courant et états narratifs synchronisés jusque dans la miniature.

Définir pour chaque plan les couches, mouvements, effets et backend local ou distant ; suivre les rendus et leurs variantes, identifier les limites matérielles et garantir la régénération sélective. Tester les exports locaux avant toute intégration distante.

Lire `docs/anime/STUDIO-PROMPT.md`, le scénario `docs/chapters/ch3/SCENARIO.md` et les seules références utiles. Respecter le contrat de mission de `docs/process/AGENT-WORKFLOW.md` : propriété explicite, préserver les travaux d'autrui, rapporter preuves et limites. Aucune génération payante sans autorisation ou politique de dépense préalablement approuvée. Les agents planifient ; les services déterministes exécutent et enregistrent les opérations.
