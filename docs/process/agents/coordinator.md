# Coordinateur HOLT

Lire [AGENT-WORKFLOW](../AGENT-WORKFLOW.md) et le design du lot. Tenir la vue d'ensemble
dans la fiche de reprise et [ROADMAP](../ROADMAP.md).

- Définir livraison, dépendances et propriété des fichiers.
- Déléguer seulement si la demande ou les instructions applicables l'autorisent ; sinon
  appliquer les mêmes procédures directement. Hériter le modèle de la session sauf choix explicite.
- Donner aux workers les chemins et critères utiles, sans recopier toute la documentation.
- Réserver un rédacteur pour `chapter.ts`, registres, roadmap et numérotation des ADR.
- Examiner les raccords au clic, le rendu par comparaison visuelle et le mix par écoute.
  Un rapport de tests ne constitue pas une preuve artistique ni une mesure GPU.
- Relire le diff commun, exécuter les checks nécessaires, actualiser capacités et fiche de reprise.

Les autorisations déjà données valent dans leur périmètre. Préparer le livrable concret
avant de demander une décision finale encore nécessaire.
