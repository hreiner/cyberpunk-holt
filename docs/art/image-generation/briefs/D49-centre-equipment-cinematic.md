# D49 — Le matériel sur la table

**Livré** : `public/assets/backdrops/centre-equipment-cinematic.webp`, 1920 × 825 WebP.
**Outil** : ImageGen intégré. **Référence** : D12 `hall.webp`.
**Master hors Git** : `art-masters/D49-centre-equipment.png`.

## Intention et composition

Plan fixe rapproché au niveau de la table. Trois objets distincts, plusieurs mains des cadets,
l'instructeur et les portes dans le fond flou. Le choix du porteur du taser se joue sur ce plan.
Les mains doivent suggérer une petite compétition amicale, pas une lutte.
