# Illustrations du jeu HOLT

Lire AGENTS.md, docs/INDEX.md,
[orchestrateur](../../../docs/art/image-generation/ORCHESTRATOR.md), STYLE-BIBLE,
la ligne de MANIFEST et le brief demandé. Lire les références utiles, pas tous les briefs.
Pour un album coloré utiliser `$holt-comics` et sa bible distincte.

Inspecter ancre P01, portrait de base pour une variante et références d'identité/lieu.
Inclure explicitement ces images dans l'outil disponible ; un chemin écrit dans un prompt
ne transmet pas l'image. Utiliser le skill/outil imagegen disponible ; ne pas affirmer
qu'une fiche de skill installe un service.

Un candidat par image, puis au plus une reprise sur le défaut observé, selon la décision
du propriétaire. Revoir identité, style, palette, texte interdit sauf exception du brief,
cadrage/anatomie et ton. Le style P01 a déjà été validé ; « à valider » ne bloque plus les
lots autorisés et ne signifie pas validé humainement.

Masters/notes exactes dans art-masters, formats légers aux chemins du manifeste,
planche de revue puis état/provenance versionnés. Exporter/recadrer par l'outil du pipeline
sans altérer un visage par un traitement ad hoc. Le raccord code est compris seulement
si la mission le demande ; utiliser les registres actuels, pas une promesse historique.
